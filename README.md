# AURA BOARD — ກຳໄລຮ້ານ

ແອັບບັນທຶກອໍເດີ ແລະ ຄິດໄລ່ກຳໄລສຳລັບຮ້ານ Aura Board ຄີບອດ

## ໂຄງສ້າງໄຟລ໌

```
aura-board-tracker/
├── index.html      ໜ້າຫຼັກ
├── css/style.css   ສະໄຕລ໌ທັງໝົດ
├── js/app.js       ໂລຈິກທັງໝົດ (ບັນທຶກ/ລົບ/ຄິດໄລ່)
└── assets/logo.jpg ໂລໂກ້ຮ້ານ
```

ຂໍ້ມູນອໍເດີຖືກເກັບໄວ້ໃນ `localStorage` ຂອງບຣາວເຊີເຄື່ອງນັ້ນໆ (ບໍ່ມີ server, ບໍ່ມີຖານຂໍ້ມູນອອນລາຍ — ຂໍ້ມູນຈະຢູ່ສະເພາະໃນອຸປະກອນ/ບຣາວເຊີທີ່ໃຊ້ບັນທຶກເທົ່ານັ້ນ).

## ວິທີເອົາຂຶ້ນ GitHub Pages (ຟຣີ, ບໍ່ຕ້ອງມີ server)

1. ສ້າງ repository ໃໝ່ໃນ GitHub ຂອງທ່ານ (ເຊັ່ນ `aura-board-tracker`)
2. ອັບໂຫຼດໄຟລ໌ທັງໝົດໃນໂຟນເດີນີ້ຂຶ້ນໄປ (ຮັກສາໂຄງສ້າງໂຟນເດີ `css/`, `js/`, `assets/` ໄວ້ຄືເກົ່າ)
   - ຈະລາກໄຟລ໌ວາງໃນໜ້າເວັບ GitHub ໂດຍກົງ ຫຼື ໃຊ້ຄຳສັ່ງລຸ່ມນີ້ກໍ່ໄດ້:
     ```
     git init
     git add .
     git commit -m "aura board profit tracker"
     git branch -M main
     git remote add origin https://github.com/<username>/aura-board-tracker.git
     git push -u origin main
     ```
3. ເຂົ້າໄປທີ່ **Settings → Pages** ຂອງ repository
4. ຫົວຂໍ້ "Branch" ເລືອກ `main` ແລະ folder ເລືອກ `/ (root)` ແລ້ວກົດ **Save**
5. ລໍຖ້າປະມານ 1-2 ນາທີ, GitHub ຈະໃຫ້ລິ້ງມາໃນຮູບແບບ:
   `https://<username>.github.io/aura-board-tracker/`
6. ເປີດລິ້ງນັ້ນຜ່ານມືຖື — ກົດ "ແຊຣ໌ → ເພີ່ມໃສ່ໜ້າຈໍຫຼັກ" (Add to Home Screen) ເພື່ອໃຫ້ໃຊ້ງານຄືແອັບແທ້ໆ

## ໝາຍເຫດ

- ຂໍ້ມູນເກັບແຍກຕາມແຕ່ລະບຣາວເຊີ/ອຸປະກອນ — ຖ້າເປີດຄົນລະເຄື່ອງ ຂໍ້ມູນຈະບໍ່ຕິດຕາມກັນ (ຖ້າຕ້ອງການໃຫ້ຂໍ້ມູນຊິງຂ້າມອຸປະກອນ ຕ້ອງຕໍ່ຖານຂໍ້ມູນອອນລາຍເພີ່ມ, ບອກໄດ້ຖ້າຢາກໃຫ້ຊ່ວຍຕໍ່)
- ຢ່າລຶບ cache/ຂໍ້ມູນເວັບບຣາວເຊີ ບໍ່ດັ່ງນັ້ນຂໍ້ມູນອໍເດີຈະຫາຍ — ແນະນຳໃຫ້ກົດ export/ຖ່າຍໜ້າຈໍສະຫຼຸບປະຈຳເດືອນເກັບໄວ້ເປັນລະຍະ
